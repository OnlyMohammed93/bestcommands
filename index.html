ڕێنیشاندەری کۆماندەکانی بۆت

تەواوی فەرمانەکانی Slash Commands و Prefix Commands

سیستەمی گیڤئاوەی (GiveAway Commands)
GiveAway-Start
Slash Prefix
شیکردنەوە:
دەستپێکردنی گیڤئاوەی نوێ لە سێرڤەر.
Slash Command:
/giveaway-start duration:1d winners:1 prize:Nitro
Prefix Command:
!gstart 1d 1 Nitro
GiveAway-End
Slash Prefix
شیکردنەوە:
کۆتایی پێهێنانی گیڤئاوەیی دەستبەجێ.
Slash Command:
/giveaway-end message_id:1552637158651600937
Prefix Command:
!gend 1552637158651600937
GiveAway-Stop
Slash Prefix
شیکردنەوە:
ڕاگرتنی گیڤئاوەی و هەڵوەشاندنەوەی بێ دیاریکردنی براوە.
Slash Command:
/giveaway-stop message_id:1552637158651600937
Prefix Command:
!gstop 1552637158651600937
GiveAway-Winner
Slash Prefix
شیکردنەوە:
دوبارە هەڵبژاردنەوەی براوە (Reroll).
Slash Command:
/giveaway-winner message_id:1552637158651600937
Prefix Command:
!greroll 1552637158651600937
GiveAway-WinnerDm
Slash Prefix
شیکردنەوە:
ناردنی نامەی تایبەت (DM) بۆ براوەی گیڤئاوەیەکە.
Slash Command:
/giveaway-winnerdm user:@username message:...
Prefix Command:
!gwinnerdm @username [message]
GiveAway-EditTime
Slash Prefix
شیکردنەوە:
دەستکاری کردنی کاتی ماوەی گیڤئاوەی بەردەوام.
Slash Command:
/giveaway-edittime message_id:1552637158651600937 time:2h
Prefix Command:
!gedittime 1552637158651600937 2h
GiveAway-EditAll
Slash Prefix
شیکردنەوە:
دەستکاریکردنی گشتی (دیاری، کات، ژمارەی براوەکان).
Slash Command:
/giveaway-editall message_id:... prize:VIP winners:2
Prefix Command:
!geditall 1552637158651600937 VIP 2

سیستەمی تیکێت (Ticket Commands)
Ticket-Lang
Slash Prefix
شیکردنەوە:
دیاریکردنی زمانی سیستەمی تیکێت (ئینگلیزی، عەرەبی، کوردی).
Slash Command:
/ticket-lang language:[en/ar/ku]
Prefix Command:
!ticket-lang [en/ar/ku]
Ticket-Setup
Slash Prefix
شیکردنەوە:
دامەزراندنی پانێڵی تیکێت.
Slash Command:
/ticket-setup channel:#support category:TICKETS
Prefix Command:
!ticket-setup #support [CategoryID]
Ticket-Open
Slash Prefix
شیکردنەوە:
کردنەوەی تیکێتی دەستی بۆ بەکارهێنەرێک.
Slash Command:
/ticket-open user:@username
Prefix Command:
!ticket-open @username
Ticket-Close
Slash Prefix
شیکردنەوە:
داخستن و سڕینەوەی چەناڵی تیکێتەکە.
Slash Command:
/ticket-close
Prefix Command:
!ticket-close
Ticket-Rename
Slash Prefix
شیکردنەوە:
گۆڕینی ناوی چەناڵی تیکێتەکە.
Slash Command:
/ticket-rename name:issue-resolved
Prefix Command:
!ticket-rename issue-resolved
Ticket-Category
Slash Prefix
شیکردنەوە:
گواستنەوەی چەناڵی تیکێت بۆ کتێگۆرییەکی تر.
Slash Command:
/ticket-category category:CLOSED-TICKETS
Prefix Command:
!ticket-category [CategoryID]
